# Reeve, Orrery, and Fettle conflict check

Checked on 2026-09-04. This is an early product-name screen, not legal advice or trademark clearance.

## Reeve

Verdict: selected as Reeve, with `omp-reeve` for the repository and package.

- [Reve](https://app.reve.com/) is an active image-generation company and model.
- [Reve 2.0](https://blog.reve.com/posts/announcing-reve-2.0/) launched in June 2026.
- [Dancode-188/reeve](https://github.com/Dancode-188/reeve) is a terminal cockpit for AI agents.
- [thaitype/reeve](https://github.com/thaitype/reeve) is a shell runtime for AI agents.
- [yetidevworks/reeve](https://github.com/yetidevworks/reeve) is an active local development stack.
- The exact [npm name `reeve`](https://www.npmjs.com/package/reeve) belongs to an old Redis helper.

The exact agent projects create category overlap. The OMP-qualified repository name separates this product from them.

Checks on 2026-09-04 found no exact `omp-reeve` GitHub repository, npm package, or macOS application.
Reve remains a spoken-name conflict, but its spelling and image-generation category differ.

## Orrery

Verdict: reject.

- [Cambridge](https://dictionary.cambridge.org/pronunciation/english/orrery) gives `OR-uh-ree`, IPA `/ˈɒr.ə.ri/`.
- [CaseyHaralson/orrery](https://github.com/CaseyHaralson/orrery) is an AI-agent orchestration CLI.
- [ito-ops/orrery](https://github.com/ito-ops/orrery) is a macOS dashboard reacting to Codex.
- [ItIsMixian/Orrery](https://github.com/ItIsMixian/Orrery) is a project-documentation skill.
- [Orrery](https://play.google.com/store/apps/details?id=com.paeliaq.orrery) is an active astronomy application.
- The [npm name `orrery`](https://www.npmjs.com/package/orrery) contains only a `0.0.0` placeholder.

The agent conflicts remain small. The difficult pronunciation creates the larger product problem.

## Fettle

Verdict: possible private codename, weak public product name.

- [Fettle](https://getfettle.app/) is an active AI assessment and deployment service.
- [fettle.app](https://www.fettle.app/) is an active portfolio and ERP software product.
- [mehatab/fettle](https://github.com/mehatab/fettle) is an active status-page project with 280 stars.
- [coryzibell/fettle](https://github.com/coryzibell/fettle) extends Claude Code file tools.
- [MilindGaharwar/fettle](https://github.com/MilindGaharwar/fettle) is a trust layer for agentic software engineering.
- The exact [npm name `fettle`](https://www.npmjs.com/package/fettle) is an old system-health dashboard placeholder.
- `fettle.app`, `fettle.dev`, `fettle.com`, and `getfettle.app` already resolve.

Fettle has the lightest sound and strongest personality of these three names.
Its active AI and software uses make future public ownership difficult.

## Result

Reeve is the selected product name. The repository and package use `omp-reeve`.
Orrery has smaller agent conflicts but fails the pronunciation test.
Fettle remains usable inside a private repository, but it carries meaningful public-release risk.
