# Security policy

Reeve runs on your machine and talks to the AI providers you configure. It stores credentials in OMP's
local database and never sends them anywhere except the provider you chose.

## Report a vulnerability

Email andrew.beniston@gmail.com with "Reeve security" in the subject. Describe the issue, the version,
and steps to reproduce. Do not open a public issue for a security problem.

You will get a reply within seven days. A fix ships as a normal release with a note in `CHANGELOG.md`.

## Supported versions

The latest release only. Reeve updates itself, so please update before you report.
